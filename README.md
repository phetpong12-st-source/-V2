HOSPITAL DASHBOARD PORTAL
=========================
โครงสร้างพร้อมสำหรับ GitHub Pages และ HTTPS

แก้ข้อมูล:
1. เปิด data.js
2. เปลี่ยน HOSPITAL.name เป็นชื่อโรงพยาบาล
3. เปลี่ยน url ของแต่ละ Dashboard เป็นลิงก์จริง
4. เพิ่ม/ลบรายการใน DASHBOARDS ได้ตามต้องการ

เผยแพร่ด้วย GitHub Pages:
1. สร้าง GitHub Repository ใหม่
2. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดในชุดนี้
3. Settings > Pages
4. Source: GitHub Actions
5. Push ไป branch main
6. GitHub Pages จะสร้าง URL HTTPS ให้
7. หากใช้โดเมนของโรงพยาบาล สามารถตั้ง Custom domain และเปิด HTTPS ได้

หมายเหตุ: HTTPS สาธารณะต้องให้ GitHub Pages/โฮสติ้งเป็นผู้ให้บริการ SSL/TLS
